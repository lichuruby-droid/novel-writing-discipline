# 写作纪律 — 《我听见她的死》

> 来源：`/workspace/novel_experience/经验副本.md` 机制蒸馏（只用机制，不复制参考书人物/剧情/原句/标志文风）。所有迁移效果默认 `待反馈`。

## 1. 每章闭环（写前→写中→写后）
写前：
0. **先通读 `连载总账.md`**（分章摘要、钩子表、人物知道/不知道、时间线、风险清单），确认本章不与已写内容冲突。
1. 在 `章节账本.md` 定：人物当下想要什么、怕失去什么、愿付什么代价；情节由欲望/偏见/盲区/代价碰撞产生。
2. 只选 **2–3 条**与本章场景相关的机制（见第 2 节），写进该章「自检」列；不塞全账，不堆公式。
3. 确认本章要交付的上章钩子 + 本章新钩子（先在 `伏笔与钩子总账.md` 登记编号）。

写中：
4. 只闭合本章主冲突，次线允许悬置；过场只留一个有关系含义的细节。
5. 章末停在新选择/误解/威胁/不可逆变化/具体动作上，**不补主题总结句**。

写后：
6. **每写完一章必须同步更新 `连载总账.md`**（按其第六节清单：摘要、钩子编号与状态、人物与关系、时间线、矛盾检查），再回填章节账本与伏笔总账；按第 4 节自检逐项过，命中惯性失误就改文，不留到下章。
6.1 **发现前后矛盾直接修，不必问用户**（用户 2026-10-30 指令）：在交付版正文里用 `<span style="color:red">…</span>` 标出改动处（删掉的字不标）；改前备份到 `正文/_bak_日期/`（`_before_fix` 后缀）；逐条写进 `正文/_bak_日期/修订记录_日期.md`（编号、章、原文→新文、口径）；需要拍板的设定选最自洽的一种，写进 `连载总账.md` 第五节「定论口径」和相关账本；改后用去掉 span 的副本跑 `chapter_selfcheck.py`，必须 0 越界。
7. 每 10 章做一次完整复盘：查钩子超期、人物独立立场、版图分层是否偷算完成。

## 2. 可调用机制（按场景取用，每条带失效条件）
- 开场：极短地点锚点后立刻进动作；单句成段只突出真跳变，滥用则信息等重。
- 钩子与兑现：上章钩子下章先交付建连载信用，兑现过满耗悬念；明确倒计时造等待，结果弱则故弄玄虚。
- 承诺与奖励：先直给类型承诺（救赎/崛起/关系）再用不可替换行为落地；小额可核验回报先于巨额回报（硬证据建信任）。
- 信息呈现：清单/账目可高效说明，但只深写最刺痛人物的一项；旁白即时澄清会压缩潜台词，按需取舍；验真只留一硬证据+一反应，不穷举。
- 人物建立：配角先有与主角无关的即时目标与压力；现实抵押物（钱/合约/风险）使妥协可信；微小数字/物件造质感，解释过多则削弱。
- 对话：看目的冲突、答非所问、打断、回避、沉默与地位变化；删一句台词若只损设定不损关系，就是资料交换，须改。
- 关系与吸引：**注意 → 试探 → 误读 → 克制 → 边界 → 风险 → 后果**，且必须改变下一步选择；外貌/美丽描写执行第3节新增「美丽描写执行规则」（用户FB-03：要详细，但分层详细，不做身体部件清单），不用生理词套装代吸引，不写「见漂亮自动心动」。
- 分层记账：已实成 / 已答应未做 / 已提议 / 他人推断 / 幻想梦境 / 未来计划分开；后来兑现不倒改前章时点。
- 同场不同目的：同场人物可各有用途地合作，不强迫全员反对男主，不把不懂等同不爱。

## 3. 本书专属规则（用户定版，不可漂移）
- **虚构化**：平行空间全虚构人名/地名/公司；不影射真实艺人，不套真实逝者经历/死因；悲剧只作救赎动机，不当爽点消费。
- **姐妹同盟低吃醋**：女主对后来姐妹同情、包容、接纳、托底；禁止雌竞、争宠、阴阳怪气抢男主；在意只写退半步/替对方圆场。爽点来自「同盟变大」，非后宫争宠。
- **成年与同意**：亲密/擦边只限成年角色当下自愿；当场同意不扩大为未来许可；边界写进发起/步骤/回应/停止机会的动作里，不写成合规条款宣讲。
- **克制擦边**：靠停顿、眼神、衣物、体温感、没说完的话造「差一步」张力；不写露骨描写，不做身体图解。欲望先推动选择，风险进后果算账，不用安全措辞把欲望抽淡，也不把欲望翻译成体面成长。
- **交付格式【用户定 2026-11-02】保持缩进**：沿用现有交付版格式——首行「# 《我听见她的死》」、`---`、「## 第00X章 标题」，正文每段段首两个全角空格「　　」，段与段之间空一行。旧章不重排。（技能 novel-writing-discipline §2.1「不缩进、标题不带书名号」与 §7 末条格式待裁决项，以本条为准，技能文本待同步。）
- **被害段阻挠者【用户定 2026-11-02】要冷不要合理**：司机/保安一类阻挠者不替自己解释算盘（不说「公司给我多少」「出事算我的」），话极少、不接话头、只做例行动作，用「对她的崩溃毫无反应」「显然不是第一次」的细节制造恐惧；理由可以藏在动作里，不说出口。去AI味诊断 rule 7「挡路的人有理由」在被害段按本条执行。
- **金手指纪律**：残响只给信息与窗口，不替人物做选择；每救一人须有现实动作（谈判/取证/舆论/法律）兑现；改错节点必须付真实代价；反噬线不许一章自愈。

- **开篇先立人、立规则、后救人（FB-01，用户定，待按新正文验证）**：开篇必须先介绍好男主（前世来历、今生处境、当下靠什么活、能力靠一件日常事做出来）与金手指（完整旁观一次：触发、旁观铁律、看到结果、带回什么、为什么不能作证据、同链不重刷与情绪残留；【用户定 2026-11-02】无冷却），读者看懂规则之后才允许第一次救援。第一卷执行口径：第001章立男主+电视初见，第002章完整残响旁观，第003章现实核验+陌生初接触受挫，第004章挣信任与布局，第005章才到救援节点。前三章禁止：完成救援、女主主动求救、男主一去就被信任、跳过金手指代价直接用先知开挂。
- **陌生人初遇与信任挣得（FB-02）**：男主与每位女主初遇均为陌生人；女主没认识过他、没求过他。他的先知在初接触时是减分项（像公司试探/跟踪/买消息），必须写出她的合理戒备。信任靠小额可核验回报挣得：先还一物/先说准一件可自查小事/说停真停/能走真放走；禁止自报残响换信任、拿结果吓人、替她做决定后记为「她信了」。关系账本在她主动留证或主动来找之前，只记「戒备/验真中」。
- **美丽描写执行规则（FB-03，用户明确偏好与既有纪律的调和口径，待确认）**：用户要求女主的漂亮要详细描写；既有研究纪律反对身体部件清单。执行为「详细，但不清单化」：(1)分层给足篇幅——首次出场可有一段相对完整的美丽印象，但拆在场景里分层落：舞台/镜头形象（灯光、造型、服装整体、编舞动作）、近距离真实状态（妆面变化、疲惫、伤痕等与剧情有关的细节）、他人反应（观众、工作人员、镜头停留、对手的态度）、男主的选择性注意（他以谈判/公关眼光钉住的那一两处，且必须改变他的判断或下一步动作）；(2)具体而不盘点：写她怎样动、怎样被光与服装托住、气场怎样压住场面，不逐项盘点身体部位、不给部位打分、不以生理反应套装代替吸引；(3)分布而不堆砌：美丽描写随出场次数逐层加深（屏幕印象→真人对照→舞台高光→私下卸妆对照），不一章倒完一张视觉卡；(4)成年口径：仅成年当下，舞台服装写整体造型与效果，不做身体图解。命中「部件清单/生理套装」仍按F005/F006自检打回；写得太略、只有「很美」空话同样打回（不合用户FB-03）。
- **金手指v2呈现纪律（FB-04/FB-05，细则见设定总纲第3节）**：触发为看到被迫害角色本人（含电视/屏幕）或触碰其贴身物件，任一单独即可、不用两个同时；深浅由载体上限决定：中介影像只能浅触发（数秒残缺碎片、可误读），长期贴身物件可深触发（完整旁观链），不得写成双条件门槛或纯章节安排；残响空间内男主是看不见的旁观者，不能说话/触碰/改变，只能看女主在场场面；呈现为迫害节点链至结果、末72小时加密；带回信息限他在空间里实际注意到的，且不能作证据，救人须在现实中重新取证落地；同一链不重刷，介入后原链失效；每次完整旁观须写情绪残留代价，不许用完即满血；【用户定 2026-11-02】不设冷却期，不得写「冷却中只给碎片」之类限制。
- **财阀线纪律**：每次版图扩张须在账本写清来源（谁带来什么证据/渠道/股份依据）；无依据暴富、对手集体降智均算失误。

## 6. 反馈与验收纪律
- 用户反馈只记：具体文本位置 + 实际感受（想继续读/出戏/人物替作者说话等）；没收到就标 `待反馈`。
- 不虚构盲评，不把自评、字数、账本完整度当进步证据；研究闭环、文本迁移、读者认可分开记状态。
- 成品不暴露模板/指标/流水线痕迹；保留口语、欲望、夸张与粗粝，不以「去 AI」为名磨平。

## 7. 爽点与节奏机制（源：经验副本机制，只用机制层）
### 7.1 钩子类型轮换（章末钩从下表轮换，相邻两章不用同一类）
| 类型 | 做法 | 失效 |
|---|---|---|
| 疑点钩 | 停在一个对不上的具体细节（时间/页码/名字） | 连续多章只抛疑点不交付，变故弄玄虚 |
| 选择钩 | 人物面临二选一且已写明两边代价，章末不揭晓选哪个 | 代价没写清时，悬念是空的 |
| 威胁钩 | 对方做出具体动作（换页/发新把柄/压热搜），不停在口头狠话 | 狠话无动作，钩子发软 |
| 倒计时钩 | 明确 72h/听证日/演出日等时限逼近 | 结果弱于等待时，倒计时反噬信用 |
| 反转钩 | 已交付信息被新证据翻面（残响外的新把柄类） | 为翻而翻、前文无伏笔支撑 |
| 情感钩 | 关系选择变化的瞬间（主动留下小证据、替对方圆场）停住 | 用电话/消息式低强钩充数（F 库弱末钩） |
- 纪律：上章钩子下章先交付一部分再开新钩，建连载信用；兑现不过满，留一层给卷级钩子（H 系列）。

### 7.2 兑现节奏（小胜先行）
- 顺序：小额可核验回报（一个时间差、一页账、一句套到的承认）→ 中胜（一人解约、一渠道站队）→ 卷级大胜（公司实成/股份/董事会）。禁止跳过小胜直接巨额兑现。
- 先剥夺后奖励只在铺垫足够时用；奖励兑现时允许人物真心兴奋，克制不天然高级。
- 真实快乐不追回：已成立的小成果不因新分歧自动撤销；要失去必须写真实后果与代价。

### 7.3 打脸方式（本书口径）
- 打脸靠证据链、谈判套话、程序反查与当事人本人发声，不靠暴力与集体降智；男主动手只限护人脱身。
- 每次打脸前，读者须已握有一块可核验碎片（公平感来源）；打脸后只留一个反应镜头，不穷举围观震惊。
- 反派受挫分阶段（见反派 defeat stage）：本卷败一层、更高层露头，禁止一章打死跨卷反派。

### 7.4 每章闭环自检提醒（与第 1、4 节合用，写后逐条过）
- [ ] 上章钩子交付了多少？本章新钩属于哪一类、与上章是否同类？
- [ ] 本章小胜是否可核验？有没有跳级兑现或无依据暴富？
- [ ] 打脸靠证据/谈判/程序，还是靠对手降智/暴力？
- [ ] 本章选的 2–3 条机制是否真改变了人物下一步选择？
- [ ] 章末停在未闭合张力，钩子编号已登记 `伏笔与钩子总账.md`？

## 8. 多 agent 复核（每章必走，用户 2026-10-19 指令）
- **触发**：每章正文写完（交付版产出后）必走，未复核不得称定稿、不得称定稿候选；状态只能写「已写/待复核」。
- **三组分开，不合并成一股找茬**：(1) 逻辑组——触发/旁观铁律、陌生人规则、年龄/金额/时间、物件连续性、钩子可核验性、账本冲突；(2) 文笔组——男主本人幽默是否在场、模板化并列/格言腔/旁白说教、美丽分层与唯一锚点、姿态清单、格式（段首两个全角空格、对白一人一段、单换行）；(3) 读者组——前段是否闷、金手指是否看懂、金手指代价、章末钩强弱、会不会继续读。复核人须带行号给证，非只打分。
- **流程**：三组独立同读当前交付版 → 汇总 PASS/PARTIAL/FAIL 与 HIGH/MED/LOW → 先修 HIGH 逻辑硬伤 → 若需改正文，改正文后同步账本并立刻回查（问题清零才交付）→ 状态推进到「待复核后试稿/待反馈」；是否定稿须由读者组结论 + 用户实读反馈两项一齐给，无一不许标定稿。
- **回执**：每章向用户报：三组各自总评、已修问题、未修问题（含章纲已定的阳谋如慢开局/章末钩弱）、状态（待反馈）；不得用复核收尾代替正文交付，正文先以干净版交付（书名《我听见她的死》+章名在前）。
- **记忆**：此规则是持续纪律，后续每章自动执行，不回退为「写完直交」；用户说停才停。

### 9.2 【写法清单】按场景取用，每个主题最多 3 条（括号内是参考书章号）
**一、残响／无力旁观**
- 错过要被一个具体的物理阻隔挡住（雨、铁轨、关掉的对讲）。顾临川看得清阻隔，搬不开（v1 1.6；二档 357、446、533／535）。 【推断】【待用户阅读反馈】
- 残响一结束，给他一件马上能做的小事，让无力接上行动（1.9；365、576）。 【推断】【待用户阅读反馈】
- 他改变的事，结果先落进一个不相干的人嘴里，他在旁边听着，不能认领（1.14；582、645、763）。 【待用户阅读反馈】

**二、阻拦者账本**
- 每个阻拦者有一句"为了自己"的话或一笔账：分成、排期、房贷，理由各不相同（2.1；7、47、318–319、552–553）。 【待用户阅读反馈】
- 转变分两三拍（僵住→后退→抢先表态），每一拍对应一件事，转完还留一点负罪感（2.4；73→78、432–433）。 【待用户阅读反馈】
- 软化写成"算了一笔新账"，消息由第三人带来，比当面道歉可信（2.11；615、717→727、785）。 【待用户阅读反馈】

**三、女主逐层自救**
- 每一级失败换一种形式：钱、人、规则、时间。坏消息叠加也有先后（3.1；233、425–429、525）。 【待用户阅读反馈】
- 每次自救都有一个精确到个位的数字：违约金、欠款、排期（3.9；597、691、851）。 【待用户阅读反馈】
- 至少有一级是被她自己挡住的，越小越好；替别人开口，被截断（3.10／3.11；582、805、832）。 【待用户阅读反馈】

**四、伤感告别**
- 救不了的那一次只完整写一遍，钉上残响时间码；以后提起只用时间码，不重演（4.13；585–586、659、862）。 【推断】【待用户阅读反馈】
- 失去写成清点和"少了一样"，物件排在眼泪前面（4.2／4.12；481、495、676、865）。 【待用户阅读反馈】
- 悲伤的最后一拍落在一件日常小事上（4.5；144、256、341）。 【待用户阅读反馈】

**五、暧昧与张力（克制成人向，配合第 3 节）**
- 每次只升一格；断在动作已经发出、结果还没落地的那一秒，或者断在"要不要"的决定处；下一章开头只给一个事后的物件（5.2／5.11；95、352、831、853）。 【待用户阅读反馈】
- 关系分级，每一级一个物件，用娱乐圈的物件（汗湿的乐谱、化妆镜上的雾气）；物件第一次出现时没人注意（5.10；672→863、780、840）。 【推断】【待用户阅读反馈】
- 任何一方说停就停，叫停的人不需要解释，接的一方负责化解尴尬；残响不进暧昧戏，不读对方意愿（5.13／5.14／14.10；751、760、788、826）。 【推断】【待用户阅读反馈】

**六、身体小动作**
- 情绪交给时长和体力：站了几分钟、走了多远。残响的时间戳正好可用（6.2；13、36、336、562）。 【推断】【待用户阅读反馈】
- 情绪落在手边的物件和声音上：杯子一声脆响、乱了的脚步。这合残响"只能看、只能听"的设定（6.7；793、827、855）。 【推断】【待用户阅读反馈】
- "本来会做却没做"的动作，是顾临川最先注意到的异常（6.8；595、604、724、752）。 【推断】【待用户阅读反馈】

**七、空白与缺席**
- 固定的信号忽然停了，空白就是预警。倒计时可以从她某个习惯中断的那天算起（7.1；80／90、562／567、785）。 【待用户阅读反馈】
- 写了又删、撤回、"正在输入"后取消。残响里可以看见她删掉的那一句（7.3；331／333、522、830、851）。 【推断】【待用户阅读反馈】
- 顾临川知道太多，最难的是不问；不敢问的话写成完整问句，但不说出口（7.5／7.8；277、406、837）。 【推断】【待用户阅读反馈】

**八、道具隔章回收**
- 给姜星遥留一个物件，出场三次：生前是日常用品，死后是证词，结尾是比喻；物件先出，前史后补（8.10；585→820→866、829→831）。 【推断】【待用户阅读反馈】
- 延迟揭晓，翻转前一场：前世误会的场景，今生在残响里看到另一半（8.3；236→238、297→351、443→445）。 【推断】【待用户阅读反馈】
- 一句旧台词原样再出现，只用一次（8.11；674–676、820）。 【待用户阅读反馈】

**九、第三方视角**
- 身份或能力被看见的时刻由旁观者完成，主角只做一个动作；最亲近的人往后退半步（9.10；598、610、765）。和第 7.3 节的冲突见 9.4-2。 【待用户阅读反馈】
- 姜星遥身边的人对她的死各有一套推理，至少一套错得合情合理（9.11；622、811、859）。 【推断】【待用户阅读反馈】
- 屏幕前的旁观者（粉丝、站姐）从她第一条动态起就在看，她死后由这个人替读者翻记录（9.12；594、828、862）。 【推断】【待用户阅读反馈】

**十、情绪容器与打断**
- 最痛的时候谈合同、谈档期，性格不变形（10.1；24、67、256、383）。 【待用户阅读反馈】
- 打断只能来自人物或场景本身（肚子叫、电梯门合上、笑场），不用公式电话或系统弹窗救场（10.3／10.4；296、438、515）。 【待用户阅读反馈】
- 人前带笑，门一关温度就降下来（10.6／10.9；598、778、862）。 【待用户阅读反馈】

**十一、段落与章末**
- 用一行时间戳或倒计时标签硬切场景；残响段落以时间戳行开头（11.5／14.6；344／346、704 起、763）。 【推断】【待用户阅读反馈】

- 引线埋在倒数第二段，最后一段只放画面（11.3；479、497）。这样 9.1 第 3 条的章末 ≤22 字才能做到。 【待用户阅读反馈】

**十二、爽点与节奏**
- 爽点落在姜星遥"被看见"、旁人的误判被打破上，顾临川少说话，反击用数据（12.1；47、138、157）。 【推断】【待用户阅读反馈】
- 有一条可见的进度（改了几件事、听到第几段），每 2–5 章一个小兑现，不做成数值面板（12.2；第 7.2 节）。 【待用户阅读反馈】

**十三、对白**

- 把对方的硬话原样还回去（13.4；401／403、535）；拒绝靠抢话、绕开、递零食（13.5；306、381、450）。 【待用户阅读反馈】

**十四、出身、称呼与圈内话（v1 14.1／14.2／14.7）**

## 10. 多书合成「我们自己的风格」（2026-10-30，待用户阅读反馈）

> 本节全部条目：【待用户阅读反馈】。迁移到本书的用法均为【推断】，不是参考书作者意图。来源：`写作技巧/写作技巧总汇.md`（五本均 100%）＋`蒸馏/多书/我们自己的风格_草案.md`。只写机制，不复制角色／剧情／标志句；不摘露骨。与 §1–§8、§9 并存；冲突以前文＋用户 FB 为准（§9.4 原冲突仍有效）。写稿每章只从本节＋§9 全库挑 **2–3 条**进自检，不堆全账。

### 10.0 用途
- 给《我听见她的死》统一调性口径：无力／旁观／逐级被挡／克制成人／章末未闭合／证据链打脸。
- **不**把总汇约 219 条可迁移写法整库粘入；细则与章号仍查总汇与风格草案。
- 硬指标底线仍按 §9.1；本节不加新硬阈值，只加机制与自检提示。

### 10.1 核心调性（写稿默认）【推断】【待用户阅读反馈】
1. **无力来自通道被堵，不来自不知情。** 他听见了，搬不开、交不出证据；爽点靠谈判／取证／舆论落地，不靠突然变强。贴残响。
2. **看得见碰不到；事后她不知道他知道。** 单方知情写成持续暗压。贴旁观。
3. **无力落在具体阻隔上**（雨、审批、合约、关掉的对讲）；残响一结束接一件能做的小事。
4. **自救每一环是可信小阻碍**（合约、舆论、好心人、合规话术），叠起来才无助；挡完留一口气。贴女团线。
5. **小胜可核验再中胜再大胜**；禁止自报残响换信任。
6. **克制成人**：升一格就停；欲望先推动选择；说停就停；不写身体图解。
7. **章末停在未闭合张力**（认知裂口／半句／物件位移），不补主题总结；钩子类型相邻章轮换（§7.1）。
8. **打脸靠证据链与程序**，不靠亮身份与全场震惊；只留 1–2 拍，亲近者退半步即可（§7.3）。
9. **关心用冷嘲、小物件、测试送出**；称谓当里程碑；摊牌前先给退出权。
10. **短叙述、口语对白、低身体词**——硬指标仍按 §9.1；可借对白推进关系，不借长段与章末长总结。

### 10.2 多书共证优先（5 条）【待用户阅读反馈】
1. **看得见／听得见，碰不到、改不了。**【共证：五本】
2. **逐级被挡**：每一环合法／可信，要价可升级。【共证：五本】
3. **误会＝巧合＋视线死角＋剪辑式半句**；翻案靠物证／同场，不靠声明稿。【共证：亿万+孟医生+僵尸+按摩师】
4. **阻拦者各有一本「为了自己」的账**；好心／正直也能挡人。【共证：魅力§9+亿万+按摩师】
5. **旁观伦理／选逃不选救／程序自我赦免**——写出「听见却不传」的道德代价（是否写入金手指代价见 10.5）。【共证：按摩师为主+四书同构】

### 10.3 各书独有、优先取用【推断】【待用户阅读反馈】
**按摩师（相对独有／高贴残响）**
- 有声无像误读；门外停住再决定推不推门；声场争夺代替亮身份；舆论风暴施工图；底层误读高层密会。
- 启用需拍板的两项见 10.5：选逃不选救、死者遗愿／残响能否当证据。

**鬼夫 CDB 专题**
- 知情却喊不出（哑口旁观）；要价升级末环＝真正受伤者放弃辩解；摊牌前给退出权；物证一条、错读两条；硬钩后软着陆，少用尖叫。

**点用（不强求每章）**
