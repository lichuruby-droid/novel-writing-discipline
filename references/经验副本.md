# 经验副本（机制蒸馏，可调用版）

> 规则：只记机制，不记参考书人物/剧情/世界观/原句。编号 T=技巧总账、D=差异总账、F=AI惯性失误库，均可回原账本查证据。凡效果判断默认「推断，待反馈」，除非注明已获后文文本支持。

## 1. 核心目标与流程（源：AGENTS.md、README.md）
- 目标：逐章研究参考小说全部写作技巧，提升原创的心理真实、关系张力、阅读牵引；不预淘汰任何技巧，每项记 机制/效果/代价/适用/失效场景；掌握=能主动选择，不是照搬。
- 研究对象是写作决策，不是复刻角色、剧情、世界观、标志句式、作者文风。区分「文本效果」与「作者真实意图」，无证据不写成事实。
- 以读者体验为准，允许鲜明审美取舍与粗粝；真人写法不等于处处更好，旧结论可被后文推翻。
- 流程调整（用户 2026-09-07 批准）：1–33 章旧同剧情实验保留；34 章起默认「逐章研究 + 全新人物/情境片段练习」，仅为控制变量时才同剧情对照并写明理由；练习标非盲，不冒称盲测。全书 1–866 章范围不变，不重做凑数。
- 语料纪律：原始文件只读；以规范化章节索引为准；三份原始文本是同一本书（497–722 重叠、758/759 取第二版），不重复计数。

## 2. 每章闭环（源：AGENTS.md 每章研究流程 1–9）
1. 事实语言总结：剧情、人物目的、关系变化、未解决问题（先事实，后解释）。
2. 选本章最重要写作难点定练习目标；练习前只调用少量相关经验，不塞全账。
3. 全新人物/关系/情境做片段；新剧情事实不是失误，查是否服务人物、前后自洽。
4. 对比机制而非句式相似：人物选择、信息隐藏、对话潜台词、场景节奏、外貌观察、吸引升级。
5. 差异入总账，复发关联 F 库；区分 单章假说 / 后文支持 / 迁移尝试 / 用户反馈，只有验证过的才升级为带边界的规则。
6. 禁空泛评分，每条结论指向具体场景功能。
7. 每项识别技巧都入技巧库，不以好/坏二分；公式感也要研究其为何提速/清晰/爽。
8. 每 10 章另写一篇不沿原剧情的完整原创章并复盘（34–43 首轮，之后 53、63…，尾轮不足10章也做）；日常片段不冒充完整章。
9. 每 100 条差异归并、查冲突、修适用范围，保留原始明细与编号；阶段汇总是调用索引，不删历史。

写前起点（成品要求）：人物当下想要什么、怕失去什么、愿付什么代价；情节由欲望/偏见/盲区/代价碰撞产生。允许偏心、虚荣、迟疑、矛盾，不刻意撒缺点造「人味」。

## 3. 技巧机制选编（源：技巧总账 T0001–T17470 抽读首尾 + 0254 样本 T17412–T17470）
调用原则：按场景取 2–3 条；每条都带失效条件，不是必用公式。
- 开场与速度：极短地点锚点后立刻进动作（T0001）；单句成段突出跳变，滥用则信息等重（T0002）；日期天气式跳时压缩重复日（T0080，见总账第4章段）。
- 钩子与兑现：上章钩子下章先交付建连载信用，兑现过满耗悬念（T0017）；明确倒计时造等待，结果弱则故弄玄虚（T0013）；先剥夺后奖励强化反弹，铺垫不足则程序化（T0015）。
- 承诺与奖励：先直给类型承诺（财富/成长/关系等）再用独特行为落地（T0011–T0012 及 D0003/D0008）；近奖拒绝+拒绝后补偿保留欲望（T0030–T0031）；小额可核验回报先于巨额（T0033，机制层：硬证据建立信任）。
- 信息呈现：UI/清单可高效承担说明（T0023），但只深写最刺痛人物的一项，其余快速通过（D0010/F014）；旁白即时澄清防误判但压缩潜台词（T0007），按需取舍。
- 人物建立：现实抵押物（钱/房/风险）限制选择使妥协可信（T0005）；玩笑式说明让对话兼交代设定，但防角色沦工具（T0006）；微小数字/物件造屈辱或质感，解释过多削弱（T0008）。
- 关系与吸引（重点维度，源 AGENTS 重点研究维度）：交流看目的冲突、答非所问、打断、回避、沉默、地位变化；外貌写观察者立场与选择性注意，不做身体部件清单；吸引写 注意→试探→误读→克制→边界→风险→后果，改变下一步，不写「见漂亮自动心动」；亲密只处理成年自愿，重点控制权与心理变化，且当场同意不扩大为未来许可（多章执行记录反复校正，属研究纪律推断）。
- 实成/计划分层（R17-02，有后文支持、仍待反馈）：已发生、已答应、已提议、他人推断、未来计划分开记；道具跨章可从属性延伸新功能，但不偷算完成（0254 样本多条）。
- 同场不同目的（R17-01，有后文支持、仍待反馈）：同场人物可各有用途地合作，不强迫全员反对主角，不把不懂等同不爱（D2101–D2200 汇总）。
- 真实快乐不追回（阶段汇总有限调用）：已成立的小成果不因新分歧自动撤销；要失去须写真实后果，不为证苦难硬撤。

## 4. 差异规律选编（源：差异总账 D0001– 起 + 第22阶段汇总）
高频可执行结论（每条回原 D 编号查边界）：
- 过场只留一个有关系含义的细节；只闭合本章主冲突，次线允许悬置（D0001/D0015）。
- 配角先有与主角无关的即时目标与压力，再谈主体性动作（D0002/D0031）。
- 先明确读者承诺，再用不可替换行为落地；清晰与主体性叠加，不互相抵消（D0003/D0008/D0022）。
- 只留一个外部硬证据+一个人物反应，不穷举验真（D0006，关联 F013）。
- 初次基线可清单，关系场景必须选择性观察（D0007）。
- 奖励兑现时允许真心兴奋，克制不天然高级（D0011）；欲望可肤浅矛盾并存，不翻译成体面成长（D0025，关联 F026）。
- 保留有功能的粗粝、冒犯、平台原生语；礼貌统一消灭圈层差异（D0024/D0080，关联 F027/F072）。
- 偏见归属人物，不替其净化，也不由旁白背书（D0016/D0043/D0099）。
- 强节点用短促反应截断，钩子后不补主题句（D0045/D0059/D0035，关联 F008/F033）。
- 道具只回收会改变因果/关系者（D0019，关联 F023/F010）。

## 5. 常犯惯性失误 F 库（源：AI惯性失误库 F001–F093 定义区 + 逐章执行记录）
格式：症状 → 修正。写作助手写后逐项自检，高频复发优先。
- F001 对话变资料交换：删台词只损设定不损关系即命中 → 给说话者不便公开的目的，允许误读。（近年执行记录中仍最高频：精准轮流、机锋过准）
- F002 情绪命名代替运作 → 用注意偏移/动作失误/回避选择表现。
- F003 人物过度合理 / F011 过度自知 → 分口头理由、自信理由、真驱动；允许体面错解被事实修正。
- F004 台词过于完整 → 只回应最刺痛/最有利部分，允许抢话回避。
- F005 外貌部件清单 / F006 生理词套装代吸引 → 只写迫使观察者改判断的细节；写选择性注意与靠近代价。
- F007 每段完成任务 / F012 质感平均分配 → 过场可粗粝，预算集中于改变关系/状态的节点。
- F008 章末总结意义 / F024 精致悖论 / F039 解释正确关系 → 停在新选择、误解、威胁、不可逆变化或具体动作。
- F009 对照句过工整 / F063 格言压变化 → 只留必要一处对照，其余让动作承担。
- F010 回声过密 / F020 闭环过满 / F023 道具必回收 → 一章一条强回声；只闭主冲突。
- F013 验真穷举 / F055 查证过量 / F031 责任链过全 → 一证据+一反应，留偶然与不可知。
- F014 每信息都人物化 / F017 每判断配小场景 / F019 资料后主题句 → 只场景化决定行动的判断。
- F015 性格台词均匀投放 / F058 群像轮流包袱 / F059 新人视觉卡片 → 允许功能反应、沉默、贡献不均；先写在做什么/想要什么。
- F016 修正意图浮表面 → 改动由人物目标与场景压力产生，不逐项反原作。
- F018 自动软化尖锐反馈 / F021 替偏见公正解释 / F022 配角动机均衡 / F034 校正动作证主体 / F047 压缩刻薄反应 → 先判尖锐的结构功能，保留冲突事实不急合成。
- F025 消息总发最佳版 / F040 自私欲望过自洽 / F053 混合动机高尚单因 / F056 功利变成长策略 → 允许泄漏、并存动机，后果检验。
- F026 欲望翻译成成长 / F061 肉欲补情感合法 / F065 二分句自辩 → 私人幻想可直白，现实互动再证自愿。

- F028 伏笔过亮 / F048 即时解码轻视 / F086 标注被避话题 → 只摆事实，让投入与缺席自己说话。
- F029 感官后即分析 / F079 简单自控讲成课 → 分析延迟到离开/反转后。

- F043–F045、F090–F093 等完整性补丁类：为细节补来源/条款/成本/合规宣布/举证请求 → 不改变决定者删，冲突真正发生时再展开。

## 6. 验收纪律（源：AGENTS.md 研究与创作验收）
- 研究完成定义：原章事实与写作决策分析 + 可识别技巧 + 当章全新情境练习（或写明理由的同剧情实验）+ 文本证据复盘 + 账本与后续验证点，全部落盘才算。
- 创作检验 5 问：新人物有无独立立场？动作与时间连续？对话是否改变人物选择？描写是否来自特定视角？读者是否想继续读？不把所有场景套同一冲突模板。
- 反馈纪律：用户反馈记具体文本位置与实际感受（想继续读/出戏/人物替作者说话等）；没收到就标待反馈，不代填、不虚构盲评、不把自评当认可。未获反馈不阻碍后续研究，但不许冒报效果。
- 证据纪律：记录量、篇幅、编号连续、自我评分不能证明进步；研究闭环、文本迁移、读者认可分别记状态。禁止空泛评分代文本证据。
- 事实层级纪律（多章校正归纳）：已实成 / 已答应未做 / 提议 / 人物推断 / 幻想梦境 / 未来计划 分层；后来兑现不倒改前章时点；推断标推断（如 0254「金派来是他人推断」类）。
- 同意与安全纪律（研究层）：当场回应只支持当场，不扩未来许可；醉/睡/权力差/拒绝未响应等只作成本分析，不作亲密模板；不复写身体图解，不把虚构设定作现实医疗/驾驶/财务依据。
- 成品纪律：分析可结构化，成品不暴露模板/指标/流水线；写前读已验证规则与人物声纹（声纹从新人物建，不移植参考角色）；保留口语、欲望、夸张、粗粝，不以「去AI」磨平。
